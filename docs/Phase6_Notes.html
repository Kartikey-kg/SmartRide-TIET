Key Concepts Explained

🔷 Custom SVG Chart Paths

Building charts without heavy canvas libraries by writing native SVG layouts in React. By calculating exact `(x, y)` coordinate mappings inside the viewport bounds (`viewBox="0 0 600 200"`), we draw smooth lines via SVG `` tags and add background gradient areas with `` fills.

🔷 Periodic Interval Countdown Clocks

Running timers inside `useEffect` with `setInterval`. A countdown reference (e.g. `10s` down to `1s`) loops every second to update a visual spinner. Upon reaching `1s`, it calls API loaders silently in the background and resets the timer, preventing visual UI flicker.

🔷 Binary Blob CSV Stream Piping

Streaming spreadsheets by sending CSV files directly as text lines over HTTP. The backend formats records into comma-separated lines and sets the headers `Content-Type: text/csv` and `Content-Disposition: attachment; filename="..."`. The frontend requests this as a `responseType: 'blob'`, creates an object URL, and triggers an automated download anchor.

🔷 Platform Override Configurations

Adjusting baseline system fields without redeploying code. Platform settings are stored in a dedicated Firebase configuration document `config/platform`. Fares checkouts and booking screens listen to this configuration to determine if new requests are allowed, surge rates apply, or warning messages should be displayed.

Frontend Architecture — Code Explained

1. Dynamic SVG Plotting Calculations

Instead of relying on external charting libraries, we map the analytics array coordinates into SVG view space. The following calculation is used inside **AdminAnalytics.jsx**:

// Map each values item to coordinate vectors within 600 x 200 viewport bounds
const values = data.map(d => d[valueKey] ?? 0);
const maxVal = Math.max(...values, 1);
const w = 600, h = 200, padX = 40, padY = 20;

const pts = values.map((v, i) => ({
  x: padX + (i / (values.length - 1 || 1)) * (w - padX * 2),
  y: padY + (1 - v / maxVal) * (h - padY * 2),
  v
}));

// Format string instructions for SVG path rendering
const linePath = pts.map((p, i) => `${i === 0 ? 'M' : 'L'}${p.x},${p.y}`).join(' ');

2. Client-Side CSV Download Streaming

To safely retrieve and save binary CSV data while attaching JWT authentication headers, we fetch files inside **AdminDashboard.jsx** using Axios `responseType: 'blob'` mappings:

const handleExportRides = async () => {
  setExportingRides(true);
  const loadId = toast.loading('Exporting rides CSV...');
  try {
    const blob = await exportRidesCSV();
    // Generate temporary download handle and trigger download
    const url = window.URL.createObjectURL(new Blob([blob]));
    const link = document.createElement('a');
    link.href = url;
    link.setAttribute('download', `rides_export_${new Date().toISOString().slice(0, 10)}.csv`);
    document.body.appendChild(link);
    link.click();
    link.parentNode.removeChild(link);
    toast.success('Rides CSV exported successfully!', { id: loadId });
  } catch (e) {
    toast.error('Failed to export rides data', { id: loadId });
  } finally {
    setExportingRides(false);
  }
};

Backend APIs — Code Explained

All backend administrative routes in `admin.routes.js` are secured using verification token and role assertion middlewares:

const { verifyToken, requireRole } = require('../middleware/auth.middleware');

// All administrative endpoints require valid token and "admin" account role
router.use(verifyToken, requireRole('admin'));
router.get('/analytics/advanced', adminController.getAdvancedAnalytics);
router.put('/drivers/:id/verify', adminController.verifyDriver);
router.get('/export/rides', adminController.exportRidesCSV);

1. Advanced Analytics Bucketing API

In `admin.controller.js`, the `/api/admin/analytics/advanced` route queries the rides collection and formats the data into daily statistics bins:

const getAdvancedAnalytics = async (req, res) => {
  try {
    const period = parseInt(req.query.period) || 7;
    const snapshot = await db.collection('rides').get();
    
    // Pre-populate array with ISO date entries
    const buckets = Array.from({ length: period }, (_, i) => {
      const d = new Date();
      d.setDate(d.getDate() - (period - 1 - i));
      return { date: d.toISOString().slice(0, 10), rides: 0, revenue: 0 };
    });

    snapshot.forEach(doc => {
      const data = doc.data();
      if (!data.createdAt) return;
      const dayStr = data.createdAt.slice(0, 10);
      const bucket = buckets.find(b => b.date === dayStr);
      if (bucket) {
        bucket.rides++;
        if (data.status === 'completed') bucket.revenue += (data.fare || 0);
      }
    });

    res.json({ buckets });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
};

Database Schema & Platforms Settings

A central configuration document is stored in Firestore at **`config/platform`** to manage global variables. When administrators adjust parameters inside **AdminSettings.jsx**, the following document structure is updated:

{
  "maintenanceMode": false,      // If true, blocks student and driver dashboard modules

  "platformMessage": "Surge pricing active due to rain", // Banner announcement string
  "updatedAt": "2026-07-08T13:21:00.000Z",
  "updatedBy": "admin_uid"
}

Errors Faced & How We Fixed Them

❌ Error 1: CSV download returns 401 Unauthorized inside new tab

Cause: Attempting to export raw datasets by triggering `window.open('/api/admin/export/rides')` failed because new browser tabs do not send client JWT authorization headers.

🔧 The Fix:

Changed the API to fetch the dataset asynchronously via Axios with the Authorization header attached, received the response as a blob, and triggered an in-page download anchor.

// Fetch dataset with authentication headers
const blob = await api.get('/admin/export/rides', { responseType: 'blob' });
const url = window.URL.createObjectURL(new Blob([blob]));
❌ Error 2: Sidebar overlap layout shifts on mobile layouts

Cause: The fixed sidebar overlay blocked page contents on small screens, preventing administrators from interacting with metrics controls.

🔧 The Fix:

Added a responsive backdrop overlay (`.asb-overlay`) that is displayed only on mobile viewports. Clicking the backdrop collapses the sidebar by updating the layout width state.
