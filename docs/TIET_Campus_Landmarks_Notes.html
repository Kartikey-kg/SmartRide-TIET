🔍 How Campus Detection Works
  • Every campus location has isCampus: true in locations.js
  • isCampusInternalTrip(locA, locB) returns true only if both endpoints have isCampus === true
  • This flag is passed as the 2nd argument to calcFare(dist, isCampusInternal)
  • If true, fare = ₹10 regardless of distance
  • If false, fare = ₹30 + ₹12/km (minimum ₹30)
💚 Campus Fare UX
  • Green ₹10 fare card border on campus trips (vs purple for off-campus)
  • "🏫 Campus Fare · flat rate" label shown under fare value
  • Green banner at top of BookRide: "Campus Rides — Flat ₹10"
  • Status banner shows "🏫 Campus Flat Rate" badge after booking
  • Campus Map page footer note: "Any ride within campus = ₹10 flat"
  • Travel time estimate uses 15 km/h for campus, 40 km/h for off-campus
📐 Updated calcFare() in rideService.js
// Campus-internal trips → flat ₹10
// Off-campus          → ₹30 base + ₹12/km (min ₹30)
export const calcFare = (distanceKm, isCampusInternal = false) => {
  if (isCampusInternal) return 10; // Flat campus fee
  const BASE = 30;
  const PER_KM = 12;
  return Math.max(BASE, Math.round(BASE + distanceKm * PER_KM));
};

🎨 CATEGORY_COLORS usage

The CATEGORY_COLORS export maps each category name to a { color, bg } object. This is used in three places:

  • BookRide.jsx — chip background and border color in the quick selector grid
  • CampusMap.jsx — pin dot color, tooltip border color, sidebar item highlight, and legend dots
  • Suggestion dropdown — "CAMPUS" badge color in BookRide search
