Key Concepts Explained

🔷 Admin Role Protection

Custom backend security middleware that executes on the server. First, verifyToken decodes the Firebase ID token in the request headers to extract the user's UID. Second, requireRole('admin') fetches their record from the Firestore "users" collection to ensure their role attribute is exactly set to "admin". Any non-admin attempts yield a 403 Forbidden error.

🔷 SVG Donut Charts (`strokeDasharray` & `strokeDashoffset`)

A circle in SVG has a circumference computed as \(2 \pi R\). By setting the circle's strokeDasharray to the size of a segment and using strokeDashoffset to rotate it, we can align multiple circles on top of each other to draw complex donut charts natively in the DOM with no external modules.

🔷 Client-Side Pagination & Filtering

Instead of hitting the Firestore database for every search keypress (which would incur huge API costs), the admin pages download the list once, then combine search input matches and filter tab clicks client-side using JavaScript array operations. Results are paginated by slicing the filtered array: filtered.slice(page * 15, (page + 1) * 15).

🔷 Firebase Auth User Deletion

When an admin deletes a user, the system must clean up both Firestore database documents (using `db.collection().doc().delete()`) and the primary credentials database in Firebase Authentication (using `auth.deleteUser(uid)` from the `firebase-admin` SDK) so the deleted user cannot log in again.

🔷 Background Polling (setInterval)

The dashboard runs a background timer using React's useEffect hook. Every 30 seconds, it triggers a silent fetch to reload metrics from the server. An active ref stores the timer index so that it can be cleared cleanly when the user exits the admin section, protecting against memory leaks.

Frontend Files — Code Explained

1. AdminDashboard.jsx (Stats & Dynamic Charts)

Displays stat summaries and translates Firestore ride logs into SVG visuals and weekly trends.

const DonutChart = ({ segments }) => {
  const total = segments.reduce((s, x) => s + x.value, 0) || 1;
  let cumulative = 0;
  const R = 44, CX = 50, CY = 50;
  const circumference = 2 * Math.PI * R;

  return (
    <svg viewBox="0 0 100 100" className="donut-svg">
      <circle cx={CX} cy={CY} r={R} fill="none" stroke="rgba(255,255,255,0.05)" strokeWidth="12" />
      {segments.map((seg, i) => {
        const pct = seg.value / total;
        const offset = circumference * (1 - cumulative);
        cumulative += pct;
        return (
          <circle
            key={i} cx={CX} cy={CY} r={R} fill="none"
            stroke={seg.color} strokeWidth="12"
            strokeDasharray={`${circumference * pct} ${circumference * (1 - pct)}`}
            strokeDashoffset={offset}
            style={{ transform: 'rotate(-90deg)', transformOrigin: '50% 50%' }}
          />
        );
      })}
    </svg>
  );
};

2. admin.controller.js

Exposes functions to execute administrative modifications safely.

const deleteUser = async (req, res) => {
  try {
    const uid = req.params.id;
    // Remove user profile from Firestore database
    await db.collection('users').doc(uid).delete();
    // Erase user identity from Firebase Auth server core
    await auth.deleteUser(uid);
    res.json({ message: 'User deleted successfully.' });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
};

Admin Analytics — How It Works

The system aggregates ride logs over the last 7 days. Here is the daily bucket calculation algorithm implemented in the controller:

const getAnalytics = async (req, res) => {
  try {
    const snapshot = await db.collection('rides').get();
    const now = new Date();
    
    // 1. Generate empty buckets for the last 7 days
    const buckets = Array.from({ length: 7 }, (_, i) => {
      const d = new Date(now);
      d.setDate(d.getDate() - (6 - i));
      return { date: d.toISOString().slice(0, 10), rides: 0, revenue: 0 };
    });

    // 2. Map rides to their corresponding date bucket
    snapshot.forEach(doc => {
      const data = doc.data();
      if (!data.createdAt) return;
      const dayStr = data.createdAt.slice(0, 10);
      const bucket = buckets.find(b => b.date === dayStr);
      if (bucket) {
        bucket.rides++;
        if (data.status === 'completed') {
          bucket.revenue += (data.fare || 0);
        }
      }
    });

    res.json({ analytics: buckets });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
};

Errors Faced & How We Fixed Them

❌ Error 1 — Admin User Self-Deletion Loophole
Admin clicks "Delete" on their own profile list card, causing self-deletion and blocking platform access.

Why it happened: The delete button was visible on every user card without checking if the target user ID matched the logged-in administrator's UID.

✅ Fix — Add a conditional check utilizing currentAdminId:
/* Hide delete button on current administrator's card */ {user.id !== currentAdminId && ( <button className="delete-btn" onClick={() => onDelete(user)}> 🗑 Delete </button> )}
❌ Error 2 — Chart Zero Division (Infinity Height render error)
TypeError: Cannot divide by zero in calculations (Rendering bar heights)

Why it happened: If the database has zero ride records, the max value evaluates to 0. Slicing with value / max * 100 causes a division-by-zero math error rendering height as Infinity.

✅ Fix — Use Math.max fallback:
// Ensure max is at least 1 const max = Math.max(...data.map(d => d.value), 1);
